# 患者ご本人・ご家族向け ユーザーガイド & 招待運用マニュアル (USER_GUIDE.md)

本ドキュメントは、**血糖値・食事・インスリン統合管理システム（リブレ・食事管理）** を日々ご利用になる **「患者ご本人」** および見守り・サポートを行う **「ご家族（共有メンバー）」** のための操作ガイドです。
また、今後新しいご家族やユーザーを招待する際の具体的な手順、セキュリティ保護の仕組み、および機能追加・仕様変更時のドキュメント更新ルールを定義しています。

---

## 1. はじめに & 3重のセキュリティ・プライバシー保護

本アプリは、医療・健康データ（血糖値・食事・インスリン投与量・活動記録）を扱うプライベートシステムです。**「URLを知っているだけの第三者が勝手に画面を閲覧したり、無断でアカウント登録して利用したりすること」を100%防ぐため、以下の3重のセキュリティ保護**（`src/components/common/AuthGateScreen.tsx` / `src/contexts/PatientContext.tsx` / `src/lib/syncEngine.ts`）が組み込まれています。

| 保護レイヤー | 仕組みと動作 |
| :--- | :--- |
| **① 専用ログイン画面（Auth Gate）による未ログイン時の完全ロック** | 本番環境では、ログインしていない状態ではカレンダー・分析・設定などの画面やメニューを一切表示せず、フルスクリーンの**専用ログイン画面（`src/components/common/AuthGateScreen.tsx`）**のみを表示します。URLを知っている第三者がアクセスしても、中身を見ることは一切できません。 |
| **② 招待制アクセス制限（オーナー本人＋事前招待された家族のみ許可）** | システムを利用できるのは**「最初のオーナー（患者ご本人）」**と、患者ご本人が事前に招待登録した**「ご家族のメールアドレス」**のみです。招待されていない第三者が勝手に「新規アカウント登録」や「ログイン」を試みても、データベース層（PostgreSQLトリガー＆RLS）とアプリ層の双方で即座に遮断・強制サインアウトされます。 |
| **③ ログアウト時の端末内データ自動消去** | 「設定」画面からログアウトを実行すると、そのパソコンやスマートフォンのブラウザ内に一時保存されていたキャッシュデータ（全7テーブルおよびメモリキャッシュ）が自動的に完全消去（`purgeAllLocalPatientCaches`）され、ログイン画面へ戻ります。共有パソコンやタブレットでも安全にご利用いただけます（クラウド上のデータは消えず安全に保管されます）。 |

## 2. 【患者ご本人向け】初回セットアップ・ログイン手順

### 2.1 初回アカウント登録（システムオーナー登録）
1. 本番アプリのURLを開くと、フルスクリーンの **「リブレ・食事管理」ログイン画面** が表示されます。
2. 上部のタブから **「新規アカウント登録」** を選択します。
3. ご自身の **メールアドレス** と **パスワード（6文字以上）** を入力し、**「アカウントを登録する」** ボタンを押します。
   - ※ 確認メールが届いた場合は、メール内の確認リンクを開いてから「ログイン」タブでログインしてください。
4. 最初に登録されたアカウントが自動的に **「患者ご本人（システムオーナー）」** として認定され、初期の食品・活動リストが準備された状態でカレンダー画面が開きます。

### 2.2 2回目以降のログインと複数端末（パソコン・スマホ）での同期
- 2回目以降は、ログイン画面の **「ログイン」** タブから同じメールアドレスとパスワードでログインしてください。
- パソコンとスマートフォンの両方で同じアカウントにログインすると、どちらの端末から記録・CSV取込を行っても自動的にクラウド経由で同期されます。

### 2.3 スマートフォンのホーム画面にアプリとして追加する方法（PWA）
- **iPhone / iPad (Safari)**：画面下部の共有ボタン（四角から上矢印）をタップし、**「ホーム画面に追加」** を選択します。
- **Android / PC (Chrome / Edge)**：「設定」タブ下部の **「ホーム画面にアプリを追加」** ボタンを押すか、ブラウザメニューから「アプリをインストール」を選択します。

## 3. 【患者ご本人向け】日常の基本操作ガイド

### 3.1 FreeStyleリブレ CSVデータの取り込み（パソコン・スマホ対応）
1. **LibreView**（またはFreeStyleリブレLink連携サイト）から、血糖値履歴のCSVファイルをダウンロードします。
2. アプリ上部の **「CSV取込」** ボタン（スマホでは画面下部中央の **「＋記録」 ➔ 「CSV取込」**）を押します（`src/components/import/CsvImportModal.tsx`）。
3. ダウンロードしたCSVファイルを選択すると、数秒で数万件の血糖値データが取り込まれ、同時に設定基準値に基づく **低血糖（▼）・高血糖（▲）エピソード** が自動抽出され、登録済みの食事記録に対して食前血糖値・食後ピーク血糖値が自動で紐づけられます。

### 3.2 カレンダー画面と日次詳細（24時間グラフ）の確認
- **カレンダー画面（`src/components/calendar/CalendarView.tsx`）**：
  - 各日のセルに「日付」「低血糖▼・高血糖▲の回数」「1日の合計糖質量（🍚）」「合計インスリン単位（💉）」「平均血糖値（🩸）」「24時間血糖ミニ波形」が一覧表示されます。
  - 日付をタップすると上部のサマリーバーが切り替わり、**選択中の日付をもう一度タップ（または上部サマリーバーをタップ）** すると **「日次詳細パネル（`src/components/daily/DailyDetailDrawer.tsx`）」** が開きます。
- **日次詳細パネル**：
  - **24時間血糖推移グラフ（`src/components/daily/DailyGlucoseChart.tsx`）**：0:00〜24:00の血糖曲線に、目標範囲（緑帯）、食事タイミング（橙●）、運動・活動（緑◆）、高血糖ピーク（赤▲）、低血糖ボトム（青▼）が重ねて表示されます。
  - **食事情報**：朝食・昼食・夕食・間食ごとの品目明細、インスリン単位、および **「食前血糖値 ➔ 食後ピーク血糖値（＋上昇幅Δ）」** が表示されます。
  - **イベント情報**：高血糖・低血糖の継続時間や最高/最低値、運動・入浴などの活動記録が時系列で表示されます。

### 3.3 食事・インスリン・活動の記録
1. 日次詳細パネル下部の **「食事を記録」** またはスマホ下部中央の **「＋記録」** を押します（`src/components/records/MealRecordModal.tsx`）。
2. 日時と区分（朝食・昼食・夕食・間食・別打ちインスリン）を選びます。
   - 日時を選ぶと、前後のリブレ測定値から **「食前血糖値」が自動入力** されます。
   - 設定画面で「デフォルトインスリン設定」をONにしている場合は、朝・昼・夕・間食に応じたインスリン単位数が自動入力されます。
3. **「登録済みの食品から選ぶ」** から食べたものを選ぶか、直接食品名と分量を入力します。未登録の食品でも **「糖質を自動推定」** ボタンでAI・日本食品標準成分表から糖質量を自動計算できます。
4. 複数の品目を追加すると **合計糖質量（g）** がリアルタイムに合算されます。**「保存する」** を押すとカレンダーとクラウドへ即座に反映されます。
5. ウォーキングや入浴などの活動は **「活動を記録」**（`src/components/records/ActivityRecordModal.tsx`）から記録できます。

### 3.4 よく使う食品・活動の整理（「食品・活動」タブ）
- **「食品・活動」** タブ（`src/components/foods/FoodMasterView.tsx`）では、普段よく食べるメニューや運動項目、およびカテゴリ（主食・主菜・副菜など）を自由に追加・編集・並び替え・削除できます。
- ここで登録した食品や活動は、毎日の記録画面の選択肢にすぐ反映されます。

### 3.5 血糖傾向の振り返り（「分析」タブ）
- **「分析」** タブ（`src/components/analysis/AnalysisView.tsx`）では、期間（7日間・14日間・30日間・90日間・月別・全期間）を切り替えて4つの視点で分析できます：
  1. **食品別血糖インパクト（`src/components/analysis/FoodImpactTab.tsx`）**：特定の食品を食べたときの食前→食後ピーク血糖上昇幅（Δ）と、その時一緒に食べた品目・インスリン量を確認できます。
  2. **時間帯別アラート傾向（`src/components/analysis/TimeAnomalyTab.tsx`）**：朝・昼・夕夜・夜間未明の4時間帯で、いつ低血糖や高血糖が起きやすいかを可視化します。
  3. **曜日別傾向（`src/components/analysis/WeekdayTrendsTab.tsx`）**：月曜〜日曜の曜日ごとの平均血糖値・糖質・インスリン量の違いを比較できます。
  4. **糖質・インスリン推移（`src/components/analysis/CarbInsulinTrendTab.tsx`）**：日々の摂取糖質量とインスリン単位数の推移を複合グラフで確認できます。

### 3.6 目標範囲の変更・デフォルトインスリン設定・バックアップ（「設定」タブ）
- **「設定」** タブ（`src/components/settings/SettingsView.tsx`）では以下の管理が行えます：
  - **血糖値の目標範囲・アラート設定**：低血糖（標準 70 mg/dL）と高血糖（標準 180 mg/dL）の基準値を変更して保存すると、過去の全データから低血糖・高血糖エピソードが自動で再計算され、クラウドとも同期されます。
  - **食事記録のデフォルトインスリン設定**：毎食の基本単位数を設定し、ON/OFFトグルで自動入力を切り替えられます。
  - **データのバックアップ・初期化**：「バックアップを保存」で全データをJSONファイルとして手元に保存でき、「バックアップから復元」でいつでも復元できます。

## 4. 【患者ご本人 & ご家族向け】新しい家族・見守りユーザーを招待する手順

今後、ご家族やパートナー、医療サポーターにデータを共有したい場合は、**必ず「① 患者ご本人による事前招待登録」を行ってから「② ご家族による初回アカウント登録」** の順に進めてください。

### 4.1 ステップ1：患者ご本人が家族のメールアドレスを招待登録する
1. **患者ご本人** のアカウントでアプリにログインし、**「設定」** タブを開きます。
2. **「家族見守り共有・クラウド同期」** セクション内の **「家族へのデータ共有・招待設定」** までスクロールします。
3. **「家族のメールアドレス」** 欄に、招待したいご家族のメールアドレスを正確に入力します。
4. **「共有する権限」** から以下のいずれかを選択します：

| 権限の種類 | ご家族ができること | おすすめのケース |
| :--- | :--- | :--- |
| **閲覧のみ（変更・削除不可）** (`viewer`) | カレンダー、日次詳細（24時間グラフ・食事内容）、データ分析の**閲覧のみ**可能。記録の追加・編集・削除・CSV取込・設定変更はすべてロック（無効化）されます。 | 離れて暮らす家族の見守り、誤操作を防いで安全にグラフや食事内容だけ共有したい場合 |
| **記録・編集も可能（代理入力可）** (`editor`) | 閲覧に加えて、**食事・インスリン・活動の記録追加や編集**が患者本人と同じように行えます（※家族招待の追加・解除は患者本人のみ可能）。 | 同居のご家族が食事内容やインスリン単位を代わりに記録・サポートする場合 |

5. **「家族を追加」** ボタンを押します。「共有中の家族一覧」にメールアドレスが追加され、**`招待中（初回ログイン待ち）`** と表示されれば準備完了です。

### 4.2 ステップ2：招待されたご家族が初回アカウント登録・ログインする
1. ご家族にアプリのURLと、「招待登録したメールアドレス」を伝えます。
2. ご家族はスマートフォンまたはパソコンでアプリのURLを開きます（専用ログイン画面が表示されます）。
3. ログイン画面上部のタブで **「新規アカウント登録」** を選択します。
4. **患者ご本人がステップ1で招待登録したものと全く同じメールアドレス** と、ご家族自身が使う **パスワード（6文字以上）** を入力し、**「アカウントを登録する」** を押します。
   - ※ 招待されていない別のメールアドレスを入力した場合は、「このアカウントにはアクセス権限がありません」と表示され登録が遮断されます。
   - ※ 確認メールが届いた場合は、メール内のリンクを開いてから「ログイン」タブでログインしてください。
5. ログインが完了すると、自動的に患者ご本人のデータと同期され、カレンダーや24時間血糖グラフが表示されます。
   - 患者ご本人の設定画面では、そのご家族のバッジが **`招待中`** から **`連携済み`** に自動的に切り替わります。
   - 2回目以降、ご家族は **「ログイン」** タブからメールアドレスとパスワードを入力するだけでいつでも最新状態を確認できます。

### 4.3 権限の変更・共有の解除（アクセス権の取り消し）方法
- **権限を変更したい場合**：
  - 患者ご本人が「設定 ＞ 家族へのデータ共有・招待設定」で、同じ家族のメールアドレスを入力し、新しい権限（「閲覧のみ」または「記録・編集も可能」）を選んで「家族を追加」を押すと、即座に権限が上書き更新されます。
- **共有を解除したい場合**：
  - 患者ご本人が「共有中の家族一覧」にある該当家族の **「共有を解除」** ボタンを押して確認ダイアログで承認すると、即座に共有が解除されます。
  - 共有を解除されたアカウントは、次回アクセス時にアクセス権限エラーとなり、データを閲覧できなくなります。

### 4.4 （管理者向け補足）Supabase 側の認証設定ポイント
ご家族を新しく招待する際、Supabase Dashboard（`Authentication` ➔ `Providers` ➔ `Email`）の設定は以下の通りにしておきます：
- **Allow new users to sign up（新規サインアップ許可）**：**ON（有効）** にしておいて問題ありません。
  - 本システムのデータベースには **未招待サインアップ遮断トリガー（`trg_enforce_invited_or_owner_signup`）** および **認可検証関数（`is_authorized_system_user`）** が組み込まれているため、Supabase 側でサインアップが ON になっていても、`family_permissions` テーブルに事前招待されていない第三者のサインアップはデータベース層で100%拒否されます。
- **Confirm email（メール確認）**：
  - ON の場合は、ご家族が新規登録した際に確認メールが届き、リンクをクリックするとログイン可能になります。
  - ご家族にメール確認の手間をかけず即座にパスワード登録だけでログインさせたい場合は、Supabase Dashboard の `Confirm email` を OFF にすることで、登録ボタンを押した瞬間にログインが完了します。

## 5. よくある質問（FAQ）・トラブルシューティング

### Q1. 家族が登録・ログインしようとすると「このアカウントにはアクセス権限がありません」と表示される
- **原因と対処**：患者ご本人の「設定 ＞ 家族へのデータ共有・招待設定」に、そのメールアドレスがまだ登録されていないか、スペルミス（別アドレス）の可能性があります。患者ご本人の画面で「共有中の家族一覧」に登録されているメールアドレスをご確認の上、同じメールアドレスで「新規アカウント登録」または「ログイン」を行ってください。

### Q2. ログアウトすると、これまで記録したデータは消えてしまいますか？
- **回答**：クラウド同期が有効な状態（ログイン中）で記録されたデータはすべてクラウド（Supabase）に安全に保存されているため、**消えません**。ログアウト時には「その端末のブラウザ内キャッシュ」だけがセキュリティ保護のために消去され、再度ログインするとクラウドから全データが自動的に復元されます。

### Q3. 外出先や病院内など、電波の届かないオフライン環境でも使えますか？
- **回答**：はい。一度ログインしてデータが同期された状態であれば、オフラインになってもカレンダーの閲覧・食事記録・糖質自動推定（内蔵の日本食品標準成分表辞書を使用）・データ分析のすべてが高速に動作します。電波が復帰した際にクラウドへ同期されます。

## 6. ドキュメント駆動開発（DDD）における随時更新ルール

本ユーザーガイド（`docs/Web_Project/USER_GUIDE.md`）は、仕様書群（SSOT: `docs/Web_Project/*.md`）の一部として **`scripts/verify-docs-sync.mjs` による機械的同期検証の対象** に組み込まれています。

今後、以下のような機能追加・仕様変更・UI改修を行う際は、開発者およびAIエージェントは関連する `SPEC_*.md` とあわせて本 `USER_GUIDE.md` を必ず同じ変更セット内で最新化してください：
1. **ログイン・認証・家族招待フロー・権限仕様の変更時**：セクション 1, 2, 4 を更新
2. **カレンダー・日次詳細・食事/活動記録・CSV取込・食品管理・分析画面の操作方法や画面構成の変更時**：セクション 3 を更新
3. **設定項目（目標範囲、インスリン設定、バックアップ等）の追加・変更時**：セクション 3.6, 5 を更新
