# Web版 血糖値・食事・インスリン統合管理システム 仕様書 (Web_Project)

本ディレクトリ（`docs/Web_Project/`）は、既存のExcel VBAシステム（`main.xlsm`）をWebアプリケーションへ刷新するための要件定義、アーキテクチャ設計、および技術仕様をまとめた仕様書群（SSOT: Single Source of Truth）です。

---

## 1. プロジェクト概要

### 1.1 Web化の目的
- **マルチデバイス同期**: PC、スマートフォン、タブレットからシームレスに日々の血糖・食事・活動を記録・閲覧可能にする。
- **オフライン動作 & 爆速操作感 (Local-First)**: クラウド通信待ち（ローディングスピナー）を排除し、Excelと同等のミリ秒単位での画面遷移・グラフ描画を実現する。
- **医療データの安全管理 & 家族見守り共有**: 複数患者のデータ完全分離（RLS）を担保しつつ、家族専用の閲覧権限（`viewer` ロール）による安全な見守り共有を標準サポートする。

## 2. 選定技術スタック一覧

```text
  [ クライアント (PC / スマホ / PWA) ]
  ┌─────────────────────────────────────────────────────────────┐
  │ React 18+ / TypeScript / Vite / Tailwind CSS / shadcn/ui    │
  │  - ローカル高速DB: IndexedDB (Dexie.js)                      │
  │  - バックグラウンド並列処理: Web Worker                      │
  │  - グラフ可視化: Apache ECharts                             │
  │  - 権限・患者コンテキスト: PatientContext (患者/家族切替)    │
  └──────────┬───────────────────────────────┬──────────────────┘
             │ ① 超高速エッジ配信           │ ③ DB同期 / 認証 (HTTPS)
             ▼                               ▼
  ┌───────────────────────┐       ┌─────────────────────────────┐
  │ Cloudflare            │       │ Supabase (PostgreSQL)       │
  │  - Pages (静的配信)   │       │  - Supabase Auth (認証・MFA)│
  │  - Workers (BFF)      │       │  - RLS (患者データ分離 & 家族閲覧)|
  │    └ Gemini APIプロキシ│       │  - Realtime (別端末の即時検知)│
  │      (JWT/同一Origin検証)│     │  - Storage (CSV原本保管 ※未実装)│
  └───────────────────────┘       └─────────────────────────────┘
```

| レイヤー | 採用技術 | 選定理由・役割 |
| :--- | :--- | :--- |
| **フロントエンド基盤** | **React + Vite + TypeScript** | コンポーネント指向、厳格な型安全性、SPA / PWA対応 |
| **UIデザイン・スタイル** | **Tailwind CSS + shadcn/ui** | 現行Excelデザイン以上の洗練されたカード・モーダルUI |
| **ローカルデータベース** | **IndexedDB (Dexie.js)** | 8.4万件超のリブレデータをブラウザ内に保持し、ミリ秒描画・オフライン動作を実現 |
| **バックグラウンド処理** | **Web Worker** | 大容量CSVパースや異常値抽出アルゴリズムをメインスレッドから分離（描画カクつき防止） |
| **グラフ・可視化** | **Apache ECharts** | 24時間血糖散布図＋垂直ドロップライン・異常マーカーの重畳描画、複合グラフ、マイクロチャート |
| **ホスティング & BFF** | **Cloudflare Pages + Workers** | エッジ配信（無料帯域無制限）、Google Gemini APIキーの安全な秘匿プロキシ（Supabase JWT / 同一Origin検証付き） |
| **クラウドBaaS & DB** | **Supabase (PostgreSQL + Auth)** | Row Level Security (RLS) による医療データ保護、家族権限管理、Realtime同期 |
| **AI外部連携** | **Google Gemini API** | 食品名からの糖質量自動推定（Workers BFF経由で中継、オフライン時は内蔵辞書へ自動フォールバック） |
