# イベント管理画面仕様書 (SPEC_EVENT_MANAGEMENT.md)

本ドキュメントは、活動マスタ（運動・家事・入浴等）を管理する画面「イベント管理（`Sheet9`）」および関連フォーム（`frmAddEventData`, `frmDailyEventManager`）の仕様書です。

---

## 1. 画面概要とレイアウト

イベント管理画面は、患者が日常的に行う「活動（運動・生活行動）」のマスタ情報を管理し、日々の活動記録で素早く呼び出せるようにするための管理画面です。食品管理画面と統一されたモダンな2カラムカードUIを採用しています。

```text
+-----------------------------------------------------------------------------------------------------------------------+
|  ■ イベント管理                                                        [+ 活動を新規登録]  [カレンダーへ戻る]        |
+-----------------------------------------------------------------------------------------------------------------------+
| [カテゴリ]                                    | [活動一覧]  (登録: 15件)                         [すべての活動を表示] |
| +-------------------------------------------+ | +-------------------------------------------------------------------+ |
| | 全て (15)                                 | | | 活動名         | カテゴリ   | 標準時間(分) | 備考             | 操作      | |
| | 有酸素運動 (5)                            | | +----------------+------------+--------------+------------------+-----------+ |
| | 筋力トレーニング (4)                      | | | ウォーキング   | 有酸素運動 | 30           | 軽い散歩         | [編集][削]| |
| | 日常生活活動 (4)                          | | | ジョギング     | 有酸素運動 | 20           | ペース維持       | [編集][削]| |
| | 未分類 (2)    ※保護・常に最下段          | | | ストレッチ     | 日常生活   | 15           | 就寝前           | [編集][削]| |
| +-------------------------------------------+ | +-------------------------------------------------------------------+ |
| [+ カテゴリ追加]  [カテゴリ編集]            |                                                                       |
+-----------------------------------------------------------------------------------------------------------------------+
```

## 2. 主要機能と制御仕様

### 2.1 日次イベント総合管理 (`frmDailyEventManager`)
指定日のすべての登録イベント（食事・活動・血糖値異常）を一覧表示・管理するハブフォームです。
- **登録件数の常時表示**:
  上部ヘッダーに「登録件数: 4件」が常に表示され、リスト内の項目選択時でも非表示になったりメッセージに置き換わったりしません。
- **操作ガイドの分離**:
  操作説明テキスト（`※イベントを選択して編集・削除が行えます`）は件数ラベルとは別の薄いサブテキストとして独立配置されています。
- **視認性の高いリストデザイン**:
  フォントサイズ（10.5pt）、行間余白、および種別別カラーアイコン（食事: 🍽️、活動: 🏃、低血糖: ⚠️青/紫、高血糖: ⚠️赤）により、一目でイベント種別を識別できます。
- **種別に応じた安全な物理ロック**:
  - 「食事」選択時: [食事を編集] ボタンが活性化 (`frmAddMealEvent` 起動)。
  - 「活動」選択時: [活動を編集] ボタンが活性化 (`frmAddEventData` 起動)。
  - 「血糖値異常」選択時: 測定ログの不可侵性規約に基づき、編集・削除ボタンは完全に非活性化（グレーアウト）。

### 2.2 活動実績の登録・編集 (`frmAddEventData`)
- **実施時刻・所要時間・自由メモ**:
  活動マスタから活動名を選択すると、標準所要時間が自動セットされます。実施時間（分）および自由メモ（体調やメモ）を入力して保存します。
- **糖質・インスリンの非保持保証**:
  活動イベントには糖質・インスリン数値は一切持たせず（テーブル上空欄）、不要な数値混入を完全に防止します。

## 3. 主要プロシージャ仕様

| プロシージャ名 | スコープ | 説明 |
| :--- | :---: | :--- |
| **`RenderEventManagementScreen`** | Public Sub | イベント管理画面全体の初期化・カード描画・カテゴリ描画・活動一覧描画を一括実行。 |
| **`FilterEventByCategory`** | Public Sub | 選択されたカテゴリ名で活動一覧をフィルタリング描画。 |
| **`ClearEventFilter`** | Public Sub | フィルタを解除し、「すべての活動」を全件表示。 |
| **`OpenAddEventDialog`** | Public Sub | `frmAddEventData` をマスタ新規登録モードで起動。 |
| **`OnEditEventClick`** | Public Sub | クリックされた行の活動マスタデータを特定し、編集モーダルを起動。 |
| **`OnDeleteEventClick`** | Public Sub | 確認ダイアログ表示後、活動マスタから物理削除。 |
