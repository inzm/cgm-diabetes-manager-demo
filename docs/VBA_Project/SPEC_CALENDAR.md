# カレンダー画面仕様書 (SPEC_CALENDAR.md)

本ドキュメントは、システムの中核となる月次ビュー画面「カレンダー（`Sheet3`）」の画面構成、集計・描画ロジック、およびイベント制御仕様を定義した仕様書です。

---

## 1. 画面概要とレイアウト

カレンダー画面は、患者の1ヶ月間の血糖・食事・インスリン状況を一望できるダッシュボード画面です。

## 2. 構成要素とセル配置

### 2.1 ヘッダーコントロール (Row 1〜3)
- **年月ナビゲーション**:
  - `B2`: 前月移動ボタン (`modCalendar.ShowPrevMonth`)
  - `D2:F2`: 現在表示年月表示（例: `2026年 10月`）
  - `H2`: 次月移動ボタン (`modCalendar.ShowNextMonth`)
  - `J2`: 今月復帰ボタン (`modCalendar.ShowCurrentMonth`)
- **アクションボタン**:
  - `L2`: 「日次詳細へ」ボタン (`modDailyDetail.ShowDailyDetail`)
  - `N2`: 「食事記録」ボタン (`frmAddMealEvent.Show`)
  - `P2`: 「活動記録」ボタン (`frmAddEventData.Show`)
  - `R2`: 「リブレ取込」ボタン (`modSettings.ImportLibreCSV`)

### 2.2 月次KPIサマリーカード (Row 4〜6)
- **月間平均血糖値**: 対象月の全測定ログ（Libreデータ）の算術平均値 (mg/dL)。
- **TIR (Time In Range)**: 血糖値が目標範囲（70〜180 mg/dL）内に収まっていた時間の割合 (%)。
- **異常値回数**: 対象月内の低血糖エピソード回数および高血糖エピソード回数の合算値。

### 2.3 カレンダーグリッド (Row 7〜37, Col B〜T)
- 7列（日〜土）× 最大6週のセルブロックで構成。
- 各日セルは縦5行（日付、糖質/インスリン、平均血糖値、スパークライン描画枠、異常値バッジ）で構成。
- **スパークライン**: 該当日の00:00〜23:59の血糖値推移をセル内にミニ折れ線グラフとして自動描画。
- **異常値バッジ**: 該当日に低血糖または高血糖が存在する場合、赤/アンバーのアイコンと回数を表示。

### 2.4 右サイドバー: 日次サマリーパネル (Col V〜Y)
- カレンダー上で選択された日付（クリックセル）のサマリーを即時表示。
- **即時描画の仕組み (O(1)高速化)**:
  `Worksheet_SelectionChange` イベント内で8.4万行のLibreデータを走査することはAGENTS.mdで厳禁とされているため、**カレンダー描画時に集計済みのセル値およびイベント記録シートから直接抽出** して 0.05 秒未満で描画を完了する。
- **構成**:
  - タイトル（`◯月◯日の概要`）＋「イベント編集」ボタン (`frmDailyEventManager`)
  - 4大KPI（糖質、インスリン、平均血糖値、異常値回数）
  - 食事情報リスト（時刻、食事区分、インスリン、糖質量）
  - イベント情報リスト（時刻、イベント名、実施時間または異常値メモ）

## 3. 主要プロシージャ仕様

| プロシージャ名 | スコープ | 説明 |
| :--- | :---: | :--- |
| **`UpdateCalendarData`** | Public Sub | 表示年月の変更時に呼び出され、グリッドの初期化、全日のKPI集計、スパークライン生成、サイドメニュー更新を一括実行。 |
| **`UpdateCalendarDayCell`** | Public Sub | イベントの追加・編集・削除時に、**該当する1日分のセルのみを差分再計算・再描画** する高速更新プロシージャ。数値が0になった際はセルを確実に空欄クリアする。 |
| **`UpdateCalendarSideMenu`** | Public Sub | 選択日（`targetDate`）を受け取り、右サイドバー（Col V〜Y）の内容を更新する。 |
| **`GetSelectedCalendarDate`** | Public Function | 現在アクティブなセル（または選択中日）から、対応する日付（Date型）を逆算・判定して返す。 |
| **`ShowPrevMonth` / `ShowNextMonth`** | Public Sub | 表示対象年月を 1 ヶ月増減させて `UpdateCalendarData` を再実行する。 |
