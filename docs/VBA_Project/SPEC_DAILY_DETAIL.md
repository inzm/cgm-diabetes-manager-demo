# 日次詳細画面仕様書 (SPEC_DAILY_DETAIL.md)

本ドキュメントは、1日単位の詳細分析画面「日次詳細（`Sheet4`）」の画面構成、24時間推移グラフ描画ロジック、タイムラインカード表示仕様を定義した仕様書です。

---

## 1. 画面概要とレイアウト

日次詳細画面は、指定日の24時間連続血糖値グラフ（FreeStyleリブレ15分値）を中心に、食事タイミング・インスリン量・異常値エピソードを重畳表示し、詳細なタイムラインカードと連動させた詳細分析画面です。

+---------------------------------------------------------------------------------------------------------------+----------------------------------+
| [4大KPIカード]                                                                                                | 糖質: 100.0g  インスリン: 26単位 |

## 2. 構成要素とセル配置

### 2.1 ヘッダーコントロール (Row 1〜3)
- **日付ナビゲーション**:
  - 前日移動ボタン (`modDailyDetail.ShowPrevDayDetail`)
  - 表示日付タイトル（例: `2026年10月1日 (木)`）
  - 翌日移動ボタン (`modDailyDetail.ShowNextDayDetail`)
  - 今日復帰ボタン (`modDailyDetail.ShowTodayDetail`)
- **アクションボタン**:
  - 「カレンダーへ戻る」ボタン (`modDailyDetail.ShowCalendarFromDetail`)
  - 「食事記録」 / 「活動記録」 / 「イベント編集」

### 2.2 4大KPIサマリーカード (Row 4〜7, Col B〜K)
- **平均血糖値**: 該当日の00:00〜23:59の全測定値（履歴グルコース）の平均。目標範囲（70〜180）内ならエメラルドグリーン、逸脱時はローズ色。
- **糖質合計**: 該当日の全食事イベントの糖質量合計 (g)。
- **インスリン量**: 該当日の投与インスリン合計 (単位)。
- **異常値回数**: 該当日に発生した低血糖および高血糖の合計エピソード数。

### 2.3 24時間血糖値推移グラフ (Row 9〜28, Col B〜R)
- **主系列 (折れ線)**: 該当日の15分間隔グルコース測定値（96ポイント）。
- **目標範囲帯 (基準線)**: 70 mg/dL（下限点線・赤色）および 180 mg/dL（上限点線・橙色）。
- **食事マーカー (縦点線＋散布図)**:
  - 食事イベントの発生時刻に縦のドット線と食事アイコン・糖質量・インスリン量をプロット。
- **異常値マーカー (散布図)**:
  - 低血糖（<70）発生箇所に下向き三角マーカー（▼）、高血糖（>180）発生箇所に上向き三角マーカー（▲）を描画。

### 2.4 右サイドバー: タイムラインカード (Col T〜W)
- **食事情報カード**:
  - ヘッダー見出し: `食事情報 (※Wクリックで詳細)`
  - 時刻、食事区分（朝食/昼食/夕食/間食）、インスリン量、糖質合計。
  - 食事ごとの区切りボーダー（淡い境界線）で整頓。
  - メモが入力されている場合は直下に薄いテキストで表示。
  - **ダブルクリック連携**: 食事行またはメモ行をダブルクリックすることで、詳細ダイアログ（食品名・分量・糖質・メモ全文）をポップアップ表示。
- **イベント情報カード**:
  - ヘッダー見出し: `イベント情報 (※Wクリックで詳細)`
  - 活動イベント: 実施時刻、活動名、`(30分)` のように時刻セル内に所要時間を統合表示。
  - 血糖値異常イベント: アイコン（▼/▲）、発生時刻、種別（低血糖/高血糖）、および `(最低 XX mg/dL (継続 XX分))` の詳細メモを確実に付加。
  - スクロールバー: イベント件数が多い場合、最大4件表示でスクロールバー連動（`OnDailyEventScroll`）。
  - **ダブルクリック連携**: イベント情報セル（Row 20〜23, Col S〜V）をダブルクリックすることで、発生時刻・種別・メモ全文（セル内で途切れた長文も含む）をポップアップ表示。
- **入力フォーム連携**:
  - 活動イベント登録・編集フォーム（`frmAddEventData`）のメモ入力欄は `MultiLine=True`, `Height=48pt`（約3行分）に拡張され、最大50文字の複数行入力に対応。

## 3. 主要プロシージャ仕様

| プロシージャ名 | スコープ | 説明 |
| :--- | :---: | :--- |
| **`ShowDailyDetail`** | Public Sub | 指定日（Date型またはシリアル値）を受け取り、シート遷移・KPI計算・グラフ描画・サイドバー更新を実行。 |
| **`UpdateDailyDetailView`** | Public Sub | 画面描画のコアエンジン。グラフオブジェクトの生成、データソース（`ChartData`）設定、およびタイムラインの構築。 |
| **`SortEventLogSheet`** | Public Sub | イベント記録シート全体を 日付（B列）・時刻（C列）で昇順ソート。**ソート範囲は必ず `A1:K`（11列）**。 |
| **`DeleteDailyEvent`** | Public Sub | イベント一覧等からイベントIDを受け取り、親レコード（`イベント記録`）および子レコード（`食事明細`）をカスケード削除。カレンダー・サイドバーを即時再計算。 |
| **`Worksheet_BeforeDoubleClick`** | Private Sub (Sheet4) | 日次詳細画面の食事・イベント情報セルをダブルクリックした際、詳細情報やメモ全文をポップアップ表示。 |
