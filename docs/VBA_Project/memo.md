## 日次詳細シート
- 済：背景色が水色になっていない、サイドメニューのデザインが他のシートと大きく異なる（枠線、背景色、フォントサイズなど）。メインコンテンツもカードデザイン調になっていない。
- 済：血糖値の推移グラフに凡例がない。
- 未検証：食事情報、イベント情報のデータが多い場合どうなるか確認する必要がある。デザインが崩れるようなら、アコーディオン式の表示にできないかを検討する。
?実現が難しい理由:
Excelワークシート上でのアコーディオン（行の展開・折りたたみ）は、行の非表示（EntireRow.Hidden）で実現可能ですが、同一行の横にある「血糖値推移グラフ」や「サイドメニュー」なども一緒に巻き込まれて縦に押し潰されたり非表示になったりする重大な制約があります。
また、VBAで行の表示/非表示を頻繁に切り替えると、画面描画の再計算負荷が高く、画面のチラつきや描画遅延の原因になります。
より実用的で洗練された代替案（推奨）:
シート上の枠内には「最新5?8件程度」をすっきり固定表示します。
件数が枠を超える場合は、枠の下部に 「他 ○ 件の記録があります [一覧・編集を開く ?]」 というリンク風のボタンを配置します。
これをクリックすると、前回作成した専用の frmDailyEventManager（日次イベント一覧・編集フォーム） が開き、スクロールしながら全件を安全・快適に閲覧・追加・編集できるようにするのが、ExcelのUIとして最も美しく壊れにくい運用となります。
- 済：「活動を記録ボタン」を配置するなら「食事を記録ボタン」も配置したほうが良いのではないか。
