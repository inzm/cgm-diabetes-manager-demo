# 分析画面仕様書 (SPEC_ANALYSIS.md)

本ドキュメントは、患者の長期的な血糖トレンド・臨床指標・生活習慣（食事・インスリン）の相関を可視化する画面「分析（`Sheet11`）」の仕様書です。

---

## 1. 開発方針と機能整理の経緯（2026年10月改訂）

システム紹介動画の制作および臨床現場での実用性を高めるため、以下の設計方針に基づき画面構成の抜本的なブラッシュアップを行いました。

### 廃止された機能とその理由
1. **AI臨床知見・アドバイス機能（Gemini API連携・更新ボタン・インサイト枠）の廃止**:
   - **理由**: 外部API通信への依存による応答遅延や、動画収録・デモ環境での動作不確実性を排除するため。また、定型的なアドバイスよりも実データに基づいた客観的な可視化グラフの方が説得力が高いため。
2. **異常日の特徴量分析テーブル（低血糖・高血糖日の比較）の廃止**:
   - **理由**: 「通常日」「低血糖日」「高血糖日」に分類した糖質比やインスリン比（糖10gあたりの単位数等）は、データ数が少ない場合の解釈が難しく、臨床現場での具体的な活用ストーリーを動画内で明快に説明しにくいため。
3. **中段 時系列 日別推移グラフ（`ChartCarbInsCombined`）の廃止**:
   - **理由**: 糖質とインスリンの日別推移は情報量が過多で視認性が低く、日付判定の不具合リスクがあったこと、また下段の「時間帯別 異常値パターン」を中段に繰り上げることで、**縦スクロールが一切不要な「1画面完結ダッシュボード（Row 1〜39）」**として劇的に操作性と見通しが向上するため。
4. **手動「分析更新」ボタン（`btnRefreshAnalysis`）の廃止**:
   - **理由**: 年月選択・食品選択・スクロールバー操作のすべてにおいて即座に自動再計算・再描画されるイベント処理（`Worksheet_Change`）が整備されており、さらに画面表示時（`Worksheet_Activate`）にも最新データへ自動更新されるため、手動ボタンを押す必要性が完全になくなった。ボタンを撤去することでヘッダーの余計な視覚的ノイズを排除し、BIダッシュボードとしての洗練度を高めた。

### ブラッシュアップ後の方向性（1画面完結・3大分析ビュー・完全自動更新）
- **左上**: 「**食品別 血糖上昇インパクト分析**」（専用スクロールバーで全件確認可能）
- **右上**: 「**曜日別 傾向分析 & グラフ**」（生活リズムの偏りと平均血糖・異常値の相関）
- **下段**: 「**時間帯別 異常値パターン**」（危険時間帯のテーブル & 横棒グラフ）
- **完全1画面完結 & 完全自動更新**: Row 1〜39 で美しく収まり、一切のスクロールおよび手動更新ボタン不要で全体の臨床傾向をシームレスに把握可能。

## 3. 各分析ビューの定義と算出ロジック

### 1. 食品別 血糖上昇インパクト分析 (`B4:M24`)
- **目的**: 患者が特定の食品を摂取した際の血糖上昇傾向を客観的に評価し、血糖スパイクの原因食品を特定する。
- **データソース**: `イベント記録`、`食事明細`、`Libreデータ`
- **算出ロジック**:
  - `食事明細` から選択食品の摂取イベントを抽出。
  - 食事開始時刻の直前15分以内の直前血糖値を取得。
  - 食後2時間（120分）以内の最高血糖値（ピーク値）を `Libreデータ` から探索。
  - 上昇幅（$\Delta$ 血糖値 = ピーク値 - 直前値）を算出。
  - $\Delta \ge 60$ mg/dL の場合は赤字・太字で「⚠️ スパイク注意」を強調表示。
- **UIおよびスクロール機能**:
  - **No. 列**: テーブル左端に通し番号（`No. 1`, `No. 2` ...）を表示。
  - **専用スクロールバー (`sbFoodImpact`)**: テーブル右横（Col M）に縦型スクロールバーを自動配置。
  - **メモリキャッシュ連動**: 全件データをメモリ配列に高速キャッシュし、スクロールバー操作時（ドラッグ・クリック）に0.01秒で13行テーブルをスライド描画。摂取回数が多い食品でも、期間内の全履歴を快適に全件確認可能。
- **表示項目**:
  - 対象食品、摂取回数、平均摂取量、平均糖質量、平均上昇幅。
  - 摂取履歴一覧（No.、日付、時刻、区分、食品名、食べた量、糖質、インスリン、直前/ピーク血糖、上昇幅Δ）。

### 2. 曜日別 傾向分析テーブル & 複合グラフ (`N4:T24`)
- **目的**: 曜日ごとの生活リズム・食事量・インスリン投与・血糖値・異常値の偏りを把握する。
- **データソース**: `イベント記録`、`Libreデータ`
- **算出項目**:
  - **平均糖質(g)**: 該当曜日の各日の合計糖質量を集計し、該当日数で除算。
  - **平均インスリン(単位)**: 該当曜日の各日の合計インスリン量を集計し、該当日数で除算。
  - **平均血糖値(mg/dL)**: 該当曜日に記録された全リブレ実測値の算術平均。
  - **異常値(回)**: 該当曜日に発生した低血糖（<70）および高血糖（>180）の合計イベント件数。
- **グラフ仕様**:
  - 第1軸（左・縦棒）: 平均血糖値（青色、最小値80〜最大値180 mg/dL、20刻みで曜日の微細な変化を明瞭化）。
  - 第2軸（右・折れ線）: 異常値発生回数（オレンジ/赤色、最小値0〜）。
  - 水曜日の行高さ均一化（22pt）によりテーブルとグラフの美観を統一。

### 3. 時間帯別 異常値パターン (`B26:T39`)
- **目的**: 低血糖および高血糖が発生しやすい時間帯（危険ゾーン）を特定し、インスリンタイミングや補食の指導に役立てる。
- **時間帯区分**:
  - 朝: 06:00 〜 11:59
  - 昼: 12:00 〜 17:59
  - 夕・夜: 18:00 〜 23:59
  - 深夜: 00:00 〜 05:59
- **テーブル構成 (`C27:H32`)**:
  - `C27:D27` 結合で「時間帯」列を確保し文字欠けを解消。
  - 低血糖件数(E)、高血糖件数(F)、合計件数(G)、全体割合(H, %) の5指標を明瞭に表示。
- **横棒グラフ (`ChartAbnormalTime`: `I27:S38`)**:
  - 集合横棒グラフ（低血糖: 青 / 高血糖: 赤）。
  - テーブルのすぐ右側にコンパクトに収まり、危険時間帯を視覚的に瞬時に判別可能。

## 4. 主要プロシージャ仕様

| プロシージャ名 | スコープ | 説明 |
| :--- | :---: | :--- |
| **`ApplyAnalysisLayout`** | Public Sub | 分析画面の4大カード枠線、背景色（`SLATE_50`）、列幅、行高、ヘッダー位置を初期化・描画。 |
| **`UpdateAllAnalysis`** | Public Sub | 選択年月に基づき、全分析ビュー（食品・曜日・推移・時間帯）を一括再集計。 |
| **`AnalyzeSelectedFood`** | Public Sub | 選択された食品について直前血糖・ピーク血糖・上昇幅・履歴テーブルを再集計。 |
| **`AnalyzeWeekdayTrends`** | Public Sub | 曜日別テーブル（糖質・インスリン・平均血糖・異常値）および複合グラフを更新。 |
| **`AnalyzePeriodTrends`** | Public Sub | 日別時系列グラフ用データ集計および時間帯別異常値テーブル・横棒グラフを更新。 |
| **`AlignAnalysisControls`** | Private Sub | ヘッダー操作ボタン（再集計・カレンダーへ戻る）やセクションアクセントバーを整列。 |
