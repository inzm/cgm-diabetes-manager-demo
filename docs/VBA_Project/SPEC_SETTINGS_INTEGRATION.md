# 設定・外部連携仕様書 (SPEC_SETTINGS_INTEGRATION.md)

本ドキュメントは、システムの臨床閾値設定、APIキー管理（`frmSettings`, `modSettings`）、およびFreeStyleリブレ生データCSVの取り込みエンジン・異常値自動抽出エンジン（`modAbnormalEvents`）の仕様書です。

---

## 1. 設定管理仕様 (`frmSettings`, `modSettings`)

設定画面は、モダンなモーダルユーザーフォーム（`frmSettings`）として実装され、どの画面からでもワンクリックで呼び出し・変更反映が可能です。

### 1.1 管理項目一覧

| 設定項目 | 型 / 範囲 | デフォルト値 | 保存先 (シート/セル) | 説明 |
| :--- | :---: | :---: | :---: | :--- |
| **低血糖閾値** | 数値 (50〜90 mg/dL) | `70` | 設定シート / B2 | この値を下回る連続測定値を低血糖エピソードとして検出。 |
| **高血糖閾値** | 数値 (140〜250 mg/dL) | `180` | 設定シート / B3 | この値を上回る連続測定値を高血糖エピソードとして検出。 |
| **目標上限値 (TIR)** | 数値 (140〜200 mg/dL) | `180` | 設定シート / B4 | TIR（Time In Range）算出時の目標上限基準。 |
| **目標下限値 (TIR)** | 数値 (60〜100 mg/dL) | `70` | 設定シート / B5 | TIR算出時の目標下限基準。 |
| **Gemini APIキー** | 文字列 (伏字入力) | - | 設定シート / B6 | Google Gemini API を呼び出すためのシークレットキー。 |

### 1.2 セキュリティ・UI制御仕様
- **APIキーの伏字化とトグル表示**:
  フォーム上のAPIキー入力欄はデフォルトでパスワード文字（`●●●●●●`）で保護。目のアイコン/チェックボックスによる「表示/非表示」トグルを実装。
- **ハードコードの完全排除**:
  コードベース内に開発用APIキー等のハードコードは一切残さず、設定シートの保護セルのみを参照・保存。
- **1クリック全画面即時反映**:
  設定保存時、カレンダー画面・日次詳細画面・分析画面の再描画をバックグラウンドで一括実行。

## 2. FreeStyleリブレCSV取込エンジン (`modSettings.ImportLibreCSV`)

FreeStyleリブレからエクスポートされたCSVファイル（数万行〜数十万行）を取り込み、システム内データベースへ追記・更新します。

### 2.1 処理フロー
1. **ファイルダイアログ**: ユーザーがリブレのエクスポートCSVを選択。
2. **通常モード（シート保護）での安全実行**:
   シートが保護された状態でもエラーを起こさないよう、取込開始時に一時的に保護を解除（`SafeUnprotect`）し、取込完了後に必ず保護を復元（`SafeProtect`）する例外安全設計。
3. **データ重複排除 (De-duplication)**:
   タイムスタンプ（日時）およびシリアル番号をキーとして、既存データと照合し、新規測定行のみを `Libreデータ` シートへ高速追記。
4. **異常値自動抽出エンジンのキック**:
   取り込み完了後、直ちに後述の `modAbnormalEvents.ExtractGlucoseAbnormalEvents` を呼び出し、新規エピソードをイベント記録へ反映。
5. **画面復帰保証**:
   取込完了後、意図せぬ別シートへ遷移せず、元のカレンダー画面の表示状態を確実に維持。

## 3. 異常値自動抽出エンジン (`modAbnormalEvents`)

Libre生データ（15分間隔グルコース値）をメモリ上で時系列走査し、臨床的な低血糖および高血糖の「連続エピソード」を自動検知して `イベント記録` シートへ一括登録するバッチエンジンです。

### 3.1 エピソード検出ロジック (State Machine)
- **低血糖判定 (< 70 mg/dL)**:
  - 血糖値が連続して 70 mg/dL 未満となった区間を1つのエピソードとしてトラッキング。
  - 区間内の **「最低到達血糖値（Lowest Glucose）」** および **「継続時間（開始時刻〜終了時刻 + 15分）」** を算出。
  - メモ形式: `最低 56 mg/dL (継続 91分)`
  - イベントID形式: `yymmdd_hhnn_LOW01`
- **高血糖判定 (> 180 mg/dL)**:
  - 血糖値が連続して 180 mg/dL 超となった区間をトラッキング。
  - 区間内の **「最高到達血糖値（Peak Glucose）」** および **「継続時間」** を算出。
  - メモ形式: `ピーク 318 mg/dL (継続 76分)`
  - イベントID形式: `yymmdd_hhnn_HIGH01`
- **データギャップ処理**:
  測定間隔が 45分 を超えて途切れている場合、前後のエピソードを分割して別エピソードとして判定。

### 3.2 テーブル書き込み仕様
- **書き込み列**: `イベント記録` シートの A〜K列（11列）。
- **値のマッピング**:
  - `A (ID)`: `yymmdd_hhnn_LOW01` / `HIGH01`
  - `B (日付)`: エピソード開始日
  - `C (時刻)`: エピソード開始時刻
  - `D (種別)`: `血糖値異常`
  - `E (区分)`: `低血糖` または `高血糖`
  - `F〜J`: 空欄（Empty）
  - `K (メモ)`: 抽出された詳細情報テキスト
