# 食品管理画面仕様書 (SPEC_FOOD_MANAGEMENT.md)

本ドキュメントは、食品マスタおよび日常食品の糖質情報を管理する画面「食品管理（`Sheet8`）」および関連フォーム（`frmAddMealData`, `frmCategoryEdit`）の仕様書です。

---

## 1. 画面概要とレイアウト

食品管理画面は、左側にカテゴリ一覧（フィルタおよび編集）、右側に食品カード一覧（動的拡張対応）を配置した2カラム構成のカードUIです。

```text
+-----------------------------------------------------------------------------------------------------------------------+
|  ■ 食品管理                                                            [+ 食品を新規登録]  [カレンダーへ戻る]        |
+-----------------------------------------------------------------------------------------------------------------------+
| [カテゴリ]                                    | [食品一覧]  (登録: 28件)                         [すべての食品を表示] |
| +-------------------------------------------+ | +-------------------------------------------------------------------+ |
| | 全て (28)                                 | | | 食品名         | カテゴリ | 基準量 | 単位 | 糖質量(g) | 操作          | |
| | 主食 (6)                                  | | +----------------+----------+--------+------+-----------+---------------+ |
| | 主菜 (8)                                  | | | 白米           | 主食     | 1      | 杯   | 55.2      | [編集] [削除] | |
| | 副菜 (7)                                  | | | 食パン (6枚切) | 主食     | 1      | 枚   | 26.6      | [編集] [削除] | |
| | デザート (4)                              | | | りんご         | デザート | 100    | g    | 15.5      | [編集] [削除] | |

| [+ カテゴリ追加]  [カテゴリ編集]            |                                                                       |
+-----------------------------------------------------------------------------------------------------------------------+
```

## 2. 主要機能と制御仕様

### 2.1 カードコンテナの動的拡張 (Dynamic Card Expansion)
- 食品件数が増加した場合、食品一覧カードの外枠（ボーダー）および白色背景（`COLOR_WHITE`）が行数に応じて的に下方向へ拡張されます。
- 余分な枠線や不要な灰色背景が残らないよう、`modFoodManagement.RenderFoodListCard` 内で描画範囲（`Range`）を厳密に計算し、カード下部のパディング行まで一括スタイリングします。

### 2.2 カテゴリ管理と「未分類」の保護 (Category Management)
- **「未分類」カテゴリの配置**:
  システム保護カテゴリ「未分類」は、カテゴリ一覧の **常に一番下（最下段）** に固定表示されます。
- **削除時の安全な引き継ぎ**:
  ユーザーが任意のカテゴリを削除した場合、そのカテゴリに属していた食品マスタのデータは自動的に「未分類」へ引き継がれ、孤立マスタの発生を防ぎます。
- **モーダル連携**:
  `frmCategoryEdit` を介して、カテゴリの追加・名称変更・削除を行います。

### 2.3 食品マスタの登録・編集 (`frmAddMealData`)
- **日常単位基準 (Daily Units)**:
  「白米1杯＝55.2g」「食パン1枚＝26.6g」のように、日常的な摂取単位でマスタが管理されます。
- **Gemini API 連携（糖質自動推定）**:
  「Geminiで検索」ボタンをクリックすると、入力された食品名に基づき Google Gemini REST API が推定糖質量と標準単位を返却し、フォーム入力欄へ自動セットします。APIキー未設定または通信エラー時でも安全な手動登録へフォールバックします。

## 3. 主要プロシージャ仕様

| プロシージャ名 | スコープ | 説明 |
| :--- | :---: | :--- |
| **`RenderFoodManagementScreen`** | Public Sub | 食品管理画面全体の初期化・カード描画・カテゴリ描画・食品一覧描画を一括実行。 |
| **`FilterFoodByCategory`** | Public Sub | 選択されたカテゴリ名で食品一覧をフィルタリング描画。 |
| **`ClearFoodFilter`** | Public Sub | フィルタを解除し、「すべての食品」を全件表示。 |
| **`OpenAddFoodDialog`** | Public Sub | `frmAddMealData` を新規登録モードで起動。 |
| **`OnEditFoodClick`** | Public Sub | クリックされた行の食品データを特定し、`frmAddMealData` を編集モードで起動。 |
| **`OnDeleteFoodClick`** | Public Sub | 確認ダイアログ表示後、食品マスタから物理削除。 |
